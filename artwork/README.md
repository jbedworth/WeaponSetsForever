# Weapon Sets Forever logo

Original vector artwork: a gold shield and crossed swords on a rich dark-brown
background. The design has no font or external-image dependencies.

- `weapon-sets-forever-logo.svg`: editable, resolution-independent source.
- `weapon-sets-forever-logo.png`: 1024 x 1024 PNG master.
- `weapon-sets-forever-logo-512.png`: 512 x 512 PNG for square project images.

Use these files for project pages and distribution branding. Keep this directory
out of the runtime release ZIP unless the AddOn later explicitly loads an asset.
The existing TOC still uses Blizzard's built-in weapon icon.
